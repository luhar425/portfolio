Artifact 02 / Written companion

Component classification and design rationale

This artifact groups the six required neural network components by their primary function. The organizing rule follows what each component contributes to a prediction or a training update. These are explanatory groups for this artifact, rather than a universal taxonomy.

Download companion PDFView the architecture slide

Classification by primary function

Six components organized into five functional groups
ComponentFunctional groupReason for placement
LayersArchitectureGroup units into input, hidden and output stages. Their order and size define the network's structure.
NeuronsArchitectureProvide the computational units within layers. Each non-input neuron combines weighted inputs and a bias, then applies an activation.
WeightsLearned parametersScale connections between units. Training adjusts them to change the model's predictions. Biases are additional learned parameters.
Activation functionsNonlinear transformationTransform a neuron's weighted input. Nonlinear functions allow a network to represent nonlinear patterns.
Loss functionsTraining objectiveCompare predictions with targets and assign an error value. The objective defines what training seeks to reduce.
Optimization algorithmsParameter updateUse gradients to update weights and biases. Backpropagation calculates the gradients that the optimizer applies.

How the components were sorted

  1. Choose a functional sorting rule

    For each component, identify its main contribution to the forward computation or training cycle. This provides a consistent basis for grouping items that look different in a diagram.

  2. Resolve overlapping roles

    A neuron uses weights and an activation, but those parts retain distinct roles. Weights are learned values; an activation is the transformation applied to their weighted sum. Layers describe structure, rather than a set of trainable values by themselves.

  3. Separate the objective from the update rule

    Loss evaluates a prediction against a target. The optimizer changes parameters to reduce that loss. Keeping these categories separate explains why backpropagation computes gradients while gradient descent applies updates.

  4. Check the categories against equations and evidence

    The worked neuron example connects the diagram to z = sum(w_i x_i) + b and a = f(z). Parameter counting confirms 18 weights plus 7 biases for the 2-4-2-1 network. Official Playground source confirms the demo's half-squared-error loss and classification output activation.

Relationships during training

During a forward pass, input features move through layers of neurons. Each neuron uses weights and a bias, then an activation, to produce a signal for the next layer. During training, the loss function compares the prediction with its target. Backpropagation calculates gradients, and the optimizer updates weights and biases for the next pass. Held-out test examples assess performance without driving these parameter updates.

The dataset classification task

The Playground experiments use supervised binary classification: the target labels distinguish two classes of points. A prediction's sign determines its class in this demo, while its continuous value contributes to the reported loss. The functional grouping of components explains the network's parts; the dataset task explains what the network predicts.

04 / Nonlinearity

Activation functions

An activation function transforms a neuron's weighted input. Nonlinear activations let stacked layers represent nonlinear patterns.

  • tanh(z)Output lies between −1 and 1.
  • ReLU(z) = max(0,z)Passes positive values and returns zero for negative values.
  • sigmoid(z) = 1/(1 + e⁻ᶻ)Output lies between 0 and 1.
  • linear(z) = zPasses the input unchanged. Stacked linear layers still form a linear mapping.

Playground changes hidden-layer activations with its menu. Its classification output always uses tanh.

05 / Measuring error

Loss functions

A loss function measures prediction error numerically. Training seeks to reduce this value.

  • Training lossError on examples used to update the model.
  • Test lossError on held-out examples, used to assess generalization.

A low training loss alone does not establish good performance on new data.

Playground's actual objective

L = (1/N) Σ ½(ŷᵢ − yᵢ)²

Mean half-squared error, including for Playground classification. This is a loss value, not a percentage or accuracy score.

Illustrative example: ½(0.4 − 1)² = 0.18. Cross entropy is common for classification outside this demo.

06 / Learning from error

Optimization algorithms

An optimization algorithm updates weights and biases to reduce loss.

01Forward pass

Compute predictions from the inputs.

02Compute loss

Compare predictions with targets.

03Backpropagate

Calculate gradients of loss with respect to parameters.

04Update and repeat

The optimizer applies the gradient updates.

w_new = w_old − η · ∂L/∂w

Learning rate η controls the step size. Small steps can take more updates. Excessive steps can oscillate or diverge.

Playground uses gradient descent on batches. These runs use batch size 10. One epoch passes through the training examples.

SGD uses single examples. Mini-batch gradient descent uses subsets. Adam adapts updates using gradient moments. Adam is context here and was not an option tested in this Playground.

09 / Key insights

Summary

Why visualization matters

  • Data flow makes the relationship between layers visible.
  • Neuron calculations connect weights and activations to a prediction.
  • Comparing training and test loss helps assess generalization.

What the exercise showed

  • Noise changed the resultThe noisy circle trial had higher test loss: 0.142 versus 0.010.
  • Features relate to geometryThe circle trial with squared features displayed 0.000 test loss at 200 epochs, with a seed caveat.
  • Capacity has a costThe larger spiral model had 137 parameters versus 25. More training reduced its test loss substantially.

Next experiment: repeat each configuration across multiple seeds at the same epoch budget.
